## Quick Start: Running the Example

### 1. Prerequisites
Ensure **Ollama** is running locally with the Gemma 4 model installed:
```bash
# Check if Ollama is running and has gemma4:e4b
curl -s http://localhost:11434/api/tags
```
If not installed:
```bash
ollama serve
ollama pull gemma4:e4b
```

### 2. Start the Backend API
```bash
cd backend
source .venv/bin/activate
uvicorn main:app --reload --port 8000
```
Verify the health endpoint:
```bash
curl -s http://localhost:8000/api/health/ollama
# Response: {"running": true, "model": "gemma4:e4b", "model_available": true}
```

### 3. Start the Frontend
```bash
cd frontend
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Run the Analysis

#### Via the Web UI:
1. Open **[http://localhost:5173/app](http://localhost:5173/app)**.
2. Upload the sample paper: [`examples/sample_input/bert_paper.pdf`](file:///Users/raj/Documents/Hacktober-fest-project/examples/sample_input/bert_paper.pdf).
3. Enter the repository URL: `https://github.com/google-research/bert`.
4. Click **Analyse**.

#### Via the Command Line (`curl`):
```bash
curl -X POST "http://localhost:8000/api/analyse" \
  -F "pdf=@examples/sample_input/bert_paper.pdf;type=application/pdf" \
  -F "repo_url=https://github.com/google-research/bert"
```
The endpoint returns a `job_id`:
```json
{"job_id": "1b1a0d47-12a3-4109-9122-b82fe1aa916e"}
```

Poll status until completion:
```bash
curl -s "http://localhost:8000/api/analyse/<job_id>/status"
```

When `done: true`, retrieve the complete report:
```bash
curl -s "http://localhost:8000/api/analyse/<job_id>/report" > my_report.json
```

## Core Guarantees Demonstrated by the Example

1. **Grounded Line Citations**: Gemma 4 is never asked to emit line numbers. Line numbers are located directly in the actual repository file content using `locate_snippet_in_file()`.
2. **Factuality Guard**: If code cannot be located verbatim in the file, line numbers are withheld (`null`) and an honest limitation notice is displayed rather than inventing references.
3. **100% Local Inference**: Zero third-party cloud APIs (Gemini, OpenAI, Anthropic). All processing stays on your machine.
